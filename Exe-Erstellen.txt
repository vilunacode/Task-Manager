============================================================
  Anleitung: Ticket-System als EXE generieren
============================================================


VORAUSSETZUNGEN
---------------
- Windows 10 oder neuer
- Internetverbindung
- Die Projektdateien (app.py, templates/, static/, etc.)


------------------------------------------------------------
SCHRITT 1 – Projektordner erstellen
------------------------------------------------------------

Erstelle einen Ordner, in dem sich alle Projektdateien
befinden sollen. Zum Beispiel:

  C:\Users\$USER\Desktop\Task-Manager

Kopiere alle Projektdateien in diesen Ordner.


------------------------------------------------------------
SCHRITT 2 – PowerShell öffnen (NICHT als Administrator)
------------------------------------------------------------

Drücke  Windows-Taste + R , tippe  powershell  und
bestatige mit Enter.

Wichtig: Nicht als Administrator starten.


------------------------------------------------------------
SCHRITT 3 – In den Projektordner wechseln
------------------------------------------------------------

  cd C:\Users\$USER\Desktop\Task-Manager

Den Pfad entsprechend anpassen, falls der Ordner woanders
liegt.


------------------------------------------------------------
SCHRITT 4 – Python installieren
------------------------------------------------------------

  pip install python3.14.5

Oder eine neuere verfuegbare Version verwenden.


------------------------------------------------------------
SCHRITT 5 – Abhängigkeiten installieren
------------------------------------------------------------

  pip install -r requirements.txt


------------------------------------------------------------
SCHRITT 6 – PyInstaller und tzdata installieren
------------------------------------------------------------

  pip install pyinstaller tzdata


------------------------------------------------------------
SCHRITT 7 – Python-Installation prüfen
------------------------------------------------------------

  python --version

Es sollte eine Versionsnummer ausgegeben werden, z. B.:
  Python 3.14.5

Falls eine Fehlermeldung erscheint, ist Python nicht korrekt
installiert oder nicht im PATH eingetragen.


------------------------------------------------------------
SCHRITT 8 – EXE generieren
------------------------------------------------------------

Folgenden Befehl als eine einzelne Zeile eingeben:

  python -m PyInstaller app.py --onefile --name Ticket-System --add-data "templates;templates" --add-data "static;static" --add-data "config.ini;." --hidden-import zoneinfo --collect-data tzdata --hidden-import flask --hidden-import werkzeug --hidden-import tkinter --noconsole --icon "thp_large.ico" --version-file "version.txt"

Der Vorgang kann einige Minuten dauern.


------------------------------------------------------------
SCHRITT 9 – EXE verwenden
------------------------------------------------------------

Nach erfolgreichem Durchlauf befinden sich zwei neue Ordner
im Projektverzeichnis:

  dist\   --> hier liegt die fertige Ticket-System.exe
  build\  --> temporäre Baudateien (kann ignoriert werden)

Beim ersten Start der EXE werden automatisch angelegt:

  config.ini       --> Konfigurationsdatei (editierbar)
  task_manager.db  --> Datenbank


------------------------------------------------------------
HINWEIS: Neu bauen nach Änderungen
------------------------------------------------------------

Wenn du nach einer Änderung am Code eine neue EXE erstellen
möchtest und der Name (z. B. "Ticket-System") gleich bleibt,
müssen zuerst die alten Dateien entfernt werden.

Lösche folgende Dateien/Ordner BEVOR du Schritt 8
wiederholt ausführst:

  - dist\Ticket-System.exe   (oder den gesamten dist\ Ordner)
  - build\Ticket-System\     (oder den gesamten build\ Ordner)
  - Ticket-System.spec

Andernfalls kann es zu Fehlermeldungen beim Bauen kommen.
